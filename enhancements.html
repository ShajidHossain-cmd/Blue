Enhancements Implemented

This page lists the extra features added to the website beyond the basic requirements.

Animated Hero Section Background

The homepage hero section has a moving gradient background using @keyframes animation. This makes the page visually dynamic and engaging.

Reference: CSS-Tricks Animations 


.hero {
  background: linear-gradient(
    135deg,
    var(--secondary-color),
    var(--primary-color),
    var(--accent-color)
  );
  background-size: 400% 400%;
  color: white;
  padding: 20px;
  text-align: center;
  margin: 0 auto;
  font-size: 2rem;
  animation: gradientMove 15s ease infinite;
}
@keyframes gradientMove {
  0% {
    background-position: 0% 50%;
  }
  50% {
    background-position: 100% 50%;
  }
  100% {
    background-position: 0% 50%;
  }
}

Animated Stats Section

The stats section now has a hover animation that scales each stat box and changes its background, making it more interactive and engaging. 


.stat-box {
  transition: transform 0.3s ease, background 0.3s ease;
}

.stat-box:hover {
  transform: scale(1.1);
  background: rgba(255, 255, 255, 0.2);
}

Responsive Hamburger Menu

The navigation bar becomes a hamburger menu on small screens using the CSS checkbox hack. Users can toggle the menu without JavaScript, improving usability on mobile devices.

Reference: CSS Tricks: Checkbox Hack 


          
/* Hide checkbox */
.menu-toggle {
  display: none;
}

/* Hamburger icon */
.menu-icon {
  display: none;
  font-size: 2rem;
  color: white;
  cursor: pointer;
  position: absolute;
  right: 20px;
  top: 15px;
}
/* Responsive nav styling */
@media (max-width: 586px) {
  /* Show hamburger */
  .menu-icon {
    display: block;
  }

  nav {
    flex-direction: column;
    align-items: center;
    position: relative;
  }

  nav ul {
    display: none;
    flex-direction: column;
    gap: 10px;
    background-color: var(--primary-color);
    position: absolute;
    top: 60px;
    left: 0;
    width: 100%;
    text-align: center;
    padding: 20px 0;
    transition: all 0.3s ease;
  }
  nav ul li:hover {
    background-color: white;
  }
  nav ul li:hover a {
    color: var(--accent-color);
  }
  /* Show menu when checkbox checked */
  .menu-toggle:checked + .menu-icon + ul {
    display: flex;
  }
}
